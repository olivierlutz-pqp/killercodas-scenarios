## Ticket d'incident

> "On a juste changé le port d'écoute de l'appli, rien d'autre. Depuis, le pod
> redémarre toutes les 30 secondes. Les logs applicatifs n'ont pourtant rien d'anormal."

**Ta mission :**

1. Confirme que l'application elle-même tourne bien (logs propres).
2. Trouve pourquoi Kubernetes considère quand même le pod comme défaillant.
3. Corrige la configuration pour stabiliser le déploiement.
